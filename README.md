# 口算练习 · Math Drill

纯前端的**口算练习小程序**：自定义算子、A/B 位数、进位/借位要求，自动出算式，用内置数字键盘作答，即时判分，并带**数据分析**面板。

🔗 在线练习：https://clonedman9.github.io/digit-calc/

## 玩法

1. 选择算子（可多选）：`＋` `－` `×` `÷`
2. 分别设置**数字 A 位数**与**数字 B 位数**（各 1 ~ 6 位，互不影响）
3. 设置**进位 / 借位要求**（见下）
4. 选择题量（10 / 20 / 30 / 无限）与每题限时
5. 点「开始练习」，用屏幕上的**数字键盘**输入答案 → 「提交」
6. 结算看正确率、平均用时、最快一题、最长连击、错题回顾
7. 右上角 📊 打开**数据分析**，看长期表现

## 进位 / 借位要求

| 选项 | 含义 |
| --- | --- |
| 不限 | 不约束，随机出题 |
| 必须进位 | 每题的计算过程中**必定发生进位/借位** |
| 禁止进位 | 每题的每一位都**不需要进位/借位** |

### 判定规则

| 算子 | 「有进位/借位」的判定 |
| --- | --- |
| `＋` | 竖式中某一列相加 ≥ 10 |
| `－` | 竖式中某一位不够减，需要向前借位 |
| `×` | 竖式相乘过程中出现进位（某位乘积 + 进位 ≥ 10） |
| `÷` | 需要**退位**：商的位数少于被除数位数 |

### 示例（来自实际需求）

| 算式 | 判定 |
| --- | --- |
| `23 + 14 = 37` | ❌ 无进位 → 「必须进位」模式下不会出现 |
| `99 − 12 = 87` | ❌ 无借位 → 「必须进位」模式下不会出现 |
| `27 + 9 = 36` | ✅ 个位 7+9=16 进位 |
| `54 − 9 = 45` | ✅ 个位 4−9 需借位 |

实现方式：加法/减法/除法用**约束采样**（不满足就重抽），乘法按进位要求**构造式生成**（例如「禁止进位」时每位取小数字，保证竖式全程不进位），因此命中率 100%；个别数学上不可能的组合（如 1 位数 − 1 位数要求借位）会自动放宽。

## 数据分析

右上角 📊 进入，数据存本地 `localStorage`，不上传：

- **总览**：总正确率、累计题数、平均用时、练习天数、错题数
- **按算子**：`＋ － × ÷` 各自的正确率与题量（横向进度条）
- **进位 / 借位表现**：有进位题 vs 无进位题的正确率对比，直接看出孩子在哪类题上卡住
- **按难度**：A 位数 + B 位数分桶（≤4 / 5-8 / 9-12 / >12）的正确率
- **最近 7 天**：每日题量柱状图，悬停显示当天题数与正确率
- 可一键清空数据

## 内置键盘

```
1  2  3
4  5  6
7  8  9
⌫  0  清空
```

- 输入框 `readonly` + `inputmode="none"`，**不弹系统键盘**
- 桌面端物理键盘照常可用：数字键、`Backspace`、`Enter`、`Esc`

## 功能清单

- ✅ A / B 位数独立滑杆（1 ~ 6 位）
- ✅ 4 个算子自由组合 + 进位/借位三档约束
- ✅ 自绘数字键盘，不弹系统键盘
- ✅ 限时模式、连击统计、错题重练
- ✅ 数据分析：算子 × 进位 × 难度 × 7 日趋势
- ✅ 深色 / 浅色主题
- ✅ 零依赖、纯静态、无后端、无数据上传

## 技术说明

- 全部运算基于原生 `BigInt`，位数拉满无浮点误差
- 出题器逐题校验：整除、非负、A/B 位数、进位/借位约束
- 状态机：`setup → drill → done / stats`，视图切换无刷新
