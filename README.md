# 口算练习 · Math Drill

纯前端的**口算练习小程序**：A/B 两个数字的位数可分别设置，自动出算式，参与者用内置数字键盘作答，即时判分并统计正确率与速度。

🔗 在线练习：https://clonedman9.github.io/digit-calc/

## 玩法

1. 选择算子（可多选）：`＋` `－` `×` `÷`
2. 分别设置**数字 A 位数**与**数字 B 位数**（各 1 ~ 6 位，互不影响）
3. 选择题量（10 / 20 / 30 / 无限）与每题限时（不限 / 10s / 20s / 30s）
4. 点「开始练习」，用屏幕上的**数字键盘**输入答案 → 「提交」
5. 每题即时反馈对错、正确答案与用时，连击累计
6. 结算看正确率、平均用时、最快一题、最长连击、错题回顾
7. 「重练错题」把本轮错题原样再出一遍

## 内置键盘

手机自带键盘会挡住题目、还容易误触，所以答题区使用自绘键盘：

```
7  8  9
4  5  6
1  2  3
⌫  0  清空
```

- 输入框设为 `readonly` + `inputmode="none"`，**不会弹出系统键盘**
- 桌面端仍可用物理键盘直接打字，`Enter` 提交、`Backspace` 删除、`Esc` 清空
- 最长 24 位，够用又防误触

## 出题规则

| 算子 | 规则 |
| --- | --- |
| `＋` | A 取 A 位数、B 取 B 位数，结果自然进位 |
| `－` | 同上；若 A < B 则交换，**不出现负数** |
| `×` | A 取 A 位数、B 取 B 位数，结果可能很长（这是设置决定的） |
| `÷` | **保证整除**：被除数取 A 位数、除数取 B 位数；商约束 ≥ 2，除数不为 1；位数不够时自动交换角色 |

## 功能清单

- ✅ A / B 位数独立滑杆（1 ~ 6 位）
- ✅ 4 个算子自由组合（多选）
- ✅ 自绘数字键盘，不弹系统键盘
- ✅ 限时模式：每题倒计时，超时判错
- ✅ 连击（streak）与最长连击
- ✅ 答错展示正确答案，结算可「重练错题」
- ✅ 结算面板：正确率 / 平均用时 / 最快一题 / 总用时 / 错题列表
- ✅ 深色 / 浅色主题，偏好本地记忆
- ✅ 零依赖、纯静态、无后端、无数据上传

## 本地运行

无需构建，直接打开 `index.html`，或：

```bash
python3 -m http.server 8080
# 打开 http://localhost:8080
```

## 部署

仓库 `main` 分支根目录即站点根目录，已开启 GitHub Pages：

```
Settings → Pages → Source: Deploy from a branch → main / (root)
```

`.nojekyll` 用于跳过 Jekyll 处理。

## 技术说明

- 全部运算基于原生 `BigInt`，位数拉满也不会有浮点误差
- 出题器对每题做约束校验：整除、非负、A/B 位数符合设置
- 状态机：`setup → drill → done`，视图切换无刷新
