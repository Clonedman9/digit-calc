# 口算练习 · Math Drill

纯前端的**口算练习小程序**：自定义算子、A/B 位数、进位/借位要求、**算式显示时长**，自动出题，内置数字键盘作答，即时判分，并带**数据分析**面板。

🔗 在线练习：https://clonedman9.github.io/digit-calc/

## 玩法

1. 选择算子（可多选）：`＋` `－` `×` `÷`
2. 分别设置**数字 A 位数**与**数字 B 位数**（各 1 ~ 6 位）
3. 设置**进位 / 借位要求**
4. 设置**算式显示时长**（见下）
5. 选择题量、每题限时 →「开始练习」
6. 用**内置数字键盘**输入答案 → 提交
7. 结算看正确率与错题；右上角 📊 看长期数据分析

## 算式显示时长（看题心算）

| 选项 | 行为 |
| --- | --- |
| 不限 | 算式一直显示 |
| 1 / 2 / 3 / 5 秒 | 到点后算式变灰并替换为 `？ ？ ？`，只剩答案输入框 |

- 设 2 秒：选手必须在 2 秒内记住算式，之后凭记忆计算
- 提交后算式会**重新完整显示**，方便对照答案复盘
- 该设置对普通练习和「重练错题」都生效

## 进位 / 借位要求

| 选项 | 含义 |
| --- | --- |
| 不限 | 不约束 |
| 必须进位 | 每题必定发生进位/借位 |
| 禁止进位 | 每位都不需要进位/借位 |

判定口径：`＋` 某列相加 ≥10 ／ `－` 某位不够减 ／ `×` 竖式相乘出现进位 ／ `÷` 需退位（商的位数 < 被除数位数）。

示例：`23+14=37` 无进位（不会出现在必须进位模式）／`27+9=36` 有进位／`99−12=87` 无借位／`54−9=45` 有借位。

实现：加减除用**约束采样**，乘法用**构造式生成**（禁止进位时每位取小数字），命中率 100%；数学上不可能的组合会自动放宽。

## 数据分析

进入后先选**数据范围**：全部 / 最近 7 天 / 今天，所有指标随之刷新。

- **总览 6 项**：正确率、题数、平均用时、总练习时长、练习天数、最长连对、错题数
- **最近 10 次练习**：每次练习（间隔 >5 分钟自动切分）的正确率柱状图，悬停看题数与时间
- **按算子**：`＋ － × ÷` 的正确率 + 题量 + 平均用时
- **进位 / 借位表现**：有进位 vs 无进位的正确率与用时对比
- **用时分布**：2 秒内 / 2-5 / 5-10 / 10 秒以上 的题量占比，并对比「答对平均用时 vs 答错平均用时」
- **难度分桶**：A+B 位数（≤4 / 5-8 / 9-12 / >12）的正确率与用时
- **最近 7 天**：每日题量柱状图
- **导出 CSV**：全部原始作答记录（时间、算子、位数、是否进位、对错、用时），可用 Excel 打开
- 可一键清空

数据存本机 `localStorage`（上限 2000 条滚动保留），不上传任何服务器。

## 内置键盘

```
1  2  3
4  5  6
7  8  9
⌫  0  清空
```

输入框 `readonly` + `inputmode="none"`，不弹系统键盘；桌面端物理键盘照常可用（数字键 / `Backspace` / `Enter` / `Esc`）。

## 功能清单

- ✅ A / B 位数独立滑杆（1 ~ 6 位）
- ✅ 4 算子自由组合 + 进位/借位三档约束
- ✅ 算式显示时长（1/2/3/5 秒后自动隐藏）
- ✅ 自绘数字键盘；限时模式；连击统计；错题重练
- ✅ 数据分析：范围筛选 × 算子 × 进位 × 用时分布 × 难度 × 7 日趋势 × CSV 导出
- ✅ 深色 / 浅色主题；零依赖、纯静态、无后端

## 本地运行

```bash
python3 -m http.server 8080
# 打开 http://localhost:8080
```

## 部署

仓库 `main` 根目录即站点根目录（GitHub Pages `main` / root），`.nojekyll` 跳过 Jekyll。

## 技术说明

- 全部运算基于原生 `BigInt`，位数拉满无浮点误差
- 出题器逐题校验：整除、非负、A/B 位数、进位/借位约束
- 统计为纯前端聚合，图表用 CSS 绘制，无第三方库
- 状态机：`setup → drill → done / stats`
