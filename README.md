# 口算练习 · Math Drill

纯前端的**口算练习小程序**：自定义算子、A/B 位数、进位/借位要求、**算式显示时长**，自动出题，内置数字键盘作答；**答题过程中不透露对错**，答完统一公布答案，并带**数据分析**面板。

🔗 在线练习：https://clonedman9.github.io/digit-calc/

## 页面结构

```
首页              设置页（独立）              练习页            结算页
┌────────────┐   ┌────────────────┐      ┌──────────┐    ┌──────────┐
│ 当前配置摘要 │   │ 算子            │      │ 算式      │    │ 正确率    │
│ 开始练习    │ ↔ │ 数字位数 A / B  │  →   │ 数字键盘   │ →  │ 作答回顾  │
│ 设置 / 数据分析 │ │ 出题规则（进位） │      │ 跳过/提交 │    │ 再来一轮  │
└────────────┘   │ 题目与时间      │      └──────────┘    └──────────┘
                 └────────────────┘
```

首页只保留「当前配置摘要 + 开始练习 + 两个入口」，所有调节项收进**独立设置页**，分 4 组：
**算子 / 数字位数 / 出题规则 / 题目与时间**。

## 玩法

1. 首页点「练习设置」，按组调好：算子、A/B 位数、进位要求、题量、限时、显示时长
2. 返回首页，配置摘要实时更新
3. 点「开始练习」，用**内置数字键盘**输入答案 → 提交
4. **不显示对错**，提交后立刻跳下一题（保持节奏、避免被反馈干扰）
5. 全部答完才公布：每题「你的答案 vs 正确答案」，默认只列出错题，可切「全部」
6. 首页点「数据分析」看长期表现

## 答题反馈

| 阶段 | 行为 |
| --- | --- |
| 答题中 | 提交即进入下一题，无 ✓/✘、无正确答案、不显示正确率与连击 |
| 结算页 | 逐题列出 `题目 / 你的答案 / 正确答案`，答错标红、答对标绿 |
| 筛选 | 结算后**默认只看错题**，可切「全部」；全对时自动回到「全部」 |

## 算式显示时长（看题心算，单位 ms）

| 选项 | 行为 |
| --- | --- |
| 不限 | 算式一直显示 |
| 500 / 1000 / 2000 ms | 到点后算式变灰并替换为 `？ ？ ？`，只剩答案输入框 |
| 自定义 | 输入任意毫秒数（50 ~ 60000），如 1500 |

- 设 1000ms：选手必须在 1 秒内记住算式，之后凭记忆计算
- 顶部会实时显示当前这一题的显示时长，如 `第 3 题 · 800ms`
- 提交后立即进入下一题，算式在结算页统一回顾
- 该设置对普通练习和「重练错题」都生效

## 自适应显示时长

勾选「自适应：答对缩短、答错延长」后，显示时长会随表现自动调整：

| 结果 | 下一题显示时长 |
| --- | --- |
| 答对 | 当前 × 0.8（越快记住越短） |
| 答错 / 超时 / 跳过 | 当前 × 1.3（没看清就放宽） |

- 从你设置的基准值开始（如 1000ms），一题一调
- 下限**可自定义**：滑杆 20 ~ 1000ms，默认 100ms；若下限高于基准，按基准截断（即不再缩短）
- 上限为 `max(基准×2, 3000ms)`，且不超过 10000ms
- 只影响「显示时长」，不影响每题限时
- 显示时长设为「不限」时自适应自动关闭；反之在「不限」状态下开启自适应，会自动把基准设为 2000ms

开启自适应后，设置页会出现「自适应最低显示时长」滑杆；关闭自适应时隐藏。

示例（基准 300ms、下限 40ms）：

```
300 → 240 → 190 → 150 → 120 → 100 → 80 → 60 → 50 → 40（触底）
```

## 可自定义的三项

| 设置 | 预设 | 自定义范围 |
| --- | --- | --- |
| 题目数量 | 10 / 20 / 30 / 无限 | 1 ~ 999 题 |
| 每题限时 | 不限 / 10s / 20s / 30s | 0.1 ~ 600 秒 |
| 算式显示时长 | 不限 / 500 / 1000 / 2000 ms | 50 ~ 60000 ms |
| 自适应 | 开 / 关 | 见上节 |
| 自适应下限 | 滑杆 20 ~ 1000ms | 默认 100ms，不超过基准 |

选中「自定义」会就地展开输入框，边输入边生效，标签实时显示当前值（如 `37 题`、`45 秒`、`800 ms`）。

## 进位 / 借位要求

| 选项 | 含义 |
| --- | --- |
| 不限 | 不约束 |
| 必须进位 | 每题必定发生进位/借位 |
| 禁止进位 | 每位都不需要进位/借位 |

判定口径：`＋` 某列相加 ≥10 ／ `－` 某位不够减 ／ `×` 竖式相乘出现进位 ／ `÷` 需退位（商的位数 < 被除数位数）。

示例：`23+14=37` 无进位（不会出现在必须进位模式）／`27+9=36` 有进位／`99−12=87` 无借位／`54−9=45` 有借位。

实现：加减除用**约束采样**，乘法用**构造式生成**（禁止进位时每位取小数字），命中率 100%；数学上不可能的组合会自动放宽。

## 数据分析

进入后先选**数据范围**：全部 / 最近 7 天 / 今天，所有指标随之刷新。

- **总览 6 项**：正确率、题数、平均用时、总练习时长、练习天数、最长连对、错题数
- **最近 10 次练习**：每次练习（间隔 >5 分钟自动切分）的正确率柱状图，悬停看题数与时间
- **按算子**：`＋ － × ÷` 的正确率 + 题量 + 平均用时
- **进位 / 借位表现**：有进位 vs 无进位的正确率与用时对比
- **用时分布**：2 秒内 / 2-5 / 5-10 / 10 秒以上 的题量占比，并对比「答对平均用时 vs 答错平均用时」
- **难度分桶**：A+B 位数（≤4 / 5-8 / 9-12 / >12）的正确率与用时
- **最近 7 天**：每日题量柱状图
- **导出 CSV**：全部原始作答记录（时间、算子、位数、是否进位、对错、用时），可用 Excel 打开
- 可一键清空

数据存本机 `localStorage`（上限 2000 条滚动保留），不上传任何服务器。

## 内置键盘

```
1  2  3
4  5  6
7  8  9
⌫  0  清空
```

输入框 `readonly` + `inputmode="none"`，不弹系统键盘；桌面端物理键盘照常可用（数字键 / `Backspace` / `Enter` / `Esc`）。

**平板/手机连点不缩放**：像 `11 × 10` 这种要连按两次 `1` 的题，双击曾被浏览器判定为「双击缩放」。现已处理：

- `touch-action: manipulation`（输入框/键盘/按钮/页面）——保留单指滚动，禁用双击与双指手势缩放
- `viewport` 加 `maximum-scale=1, user-scalable=no`
- 按键改用 `pointerdown` 录入（无 300ms 点击延迟），并对浏览器补发的配对 `click` 计数去重，长按后松开也不会重复录入

## 功能清单

- ✅ A / B 位数独立滑杆（1 ~ 6 位）
- ✅ 4 算子自由组合 + 进位/借位三档约束
- ✅ 算式显示时长（ms 级，预设 + 自定义，到点自动隐藏）
- ✅ 题量 / 限时 / 显示时长均可自定义
- ✅ 自绘数字键盘；限时模式；连击统计；错题重练
- ✅ 数据分析：范围筛选 × 算子 × 进位 × 用时分布 × 难度 × 7 日趋势 × CSV 导出
- ✅ 深色 / 浅色主题；零依赖、纯静态、无后端

## 技术说明

- 全部运算基于原生 `BigInt`，位数拉满无浮点误差
- 出题器逐题校验：整除、非负、A/B 位数、进位/借位约束
- 统计为纯前端聚合，图表用 CSS 绘制，无第三方库
- 状态机：`setup → drill → done / stats`
