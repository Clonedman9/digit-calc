# 口算练习 · Math Drill

一个纯前端的**口算练习小程序**：自定义算子与位数 → 自动出算式 → 参与者作答 → 即时判分 → 统计正确率与速度。

🔗 在线练习：https://clonedman9.github.io/digit-calc/

## 玩法

1. 选择算子（可多选）：`＋` `－` `×` `÷`
2. 拖动滑杆设置**数字位数**（1 ~ 6 位）
3. 选择题量（10 / 20 / 30 / 无限）与每题限时（不限 / 10s / 20s / 30s）
4. 点「开始练习」，在输入框写下答案，按 `Enter` 提交
5. 每题即时反馈对错与正确答案，连击累计
6. 结束后看结算：正确率、平均用时、最快一题、最长连击、错题回顾
7. 支持「重练错题」——把本轮错题原样再来一遍

## 出题规则（保证题目可心算）

| 算子 | 规则 |
| --- | --- |
| `＋` | 两个数均为设定位数，结果自然进位 |
| `－` | 被减数 ≥ 减数，**不出现负数**；结果位数不低于位数 −1 |
| `×` | 被乘数为设定位数，乘数最多 2 位，避免过于变态 |
| `÷` | **保证整除**：先定除数与被除数位数，再取整数商 |

## 功能

- ✅ 6 档位数、4 种算子自由组合
- ✅ 限时模式：每题倒计时，超时自动判错
- ✅ 连击（streak）与最长连击统计
- ✅ 答错自动展示正确答案，本轮结束可「重练错题」
- ✅ 结算面板：正确率 / 平均用时 / 最快一题 / 总用时 / 错题列表
- ✅ 全键盘操作（`Enter` 提交），手机端数字键盘
- ✅ 深色 / 浅色主题，偏好本地记忆
- ✅ 零依赖、纯静态、无后端、无数据上传

## 本地运行

无需构建，直接打开 `index.html`，或：

```bash
python3 -m http.server 8080
# 打开 http://localhost:8080
```

## 部署

仓库 `main` 分支根目录即站点根目录，已开启 GitHub Pages：

```
Settings → Pages → Source: Deploy from a branch → main / (root)
```

`.nojekyll` 用于跳过 Jekyll 处理。

## 技术说明

- 全部运算基于原生 `BigInt`，位数拉满也不会出现浮点误差
- 出题器对每题做约束校验（整除、非负、位数），见 `README` 表格
- 状态机：`setup → drill → done`，视图切换无刷新
