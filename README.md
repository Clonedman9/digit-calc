# 数感 · Digit Calc

纯前端的**口算练习小程序**：自定义算子、A/B 位数、进位/借位要求、**算式显示时长**，自动出题，内置数字键盘作答；**答题过程中不透露对错**，答完统一公布答案，并带**数据分析**面板。

🔗 在线练习：https://clonedman9.github.io/digit-calc/

## 界面与页面结构

采用低饱和森林绿与暖白的安静工作空间，默认浅色，也保留深色主题：

- **首页**：当前配置、开始按钮、设置/数据入口，以及来自真实本机记录的题量、正确率和平均用时。
- **设置**：运算、数字位数、出题规则、题目与时间四组；桌面双栏，手机单栏。更改自动保存并在刷新后恢复。
- **练习**：题干在屏幕上方居中，下方是一个居中大键盘；平板与桌面训练时隐藏侧栏，占用完整屏幕宽度。键盘不拆分，左右手可操作同一套数字键。手机保持单栏紧凑布局。
- **结算**：正确率、四项指标、逐题回顾与错题重练。
- **分析**：范围筛选、概览、六组表现与趋势卡片、CSV 导出。

桌面采用侧边导航；手机采用底部导航；平板自动收为图标栏。支持实体键盘、清晰焦点、输入控件名称、屏幕阅读器状态提示和减少动态效果偏好。页面使用本地 CSS/JS、内联 SVG 和系统字体，没有运行时 CDN 依赖。

## 玩法

1. 首页点「练习设置」，按组调好：算子、A/B 位数、进位要求、题量、限时、显示时长
2. 返回首页，配置摘要实时更新
3. 点「开始练习」，用**内置数字键盘**输入答案 → 提交
4. **不显示对错**，提交后立刻跳下一题（保持节奏、避免被反馈干扰）
5. 全部答完才公布：每题「你的答案 vs 正确答案」，默认只列出错题，可切「全部」
6. 首页点「数据分析」看长期表现

## 答题反馈

| 阶段 | 行为 |
| --- | --- |
| 答题中 | 提交即进入下一题，无 ✓/✘、无正确答案、不显示正确率与连击 |
| 结算页 | 逐题列出 `题目 / 你的答案 / 正确答案`，答错标红、答对标绿 |
| 筛选 | 结算后**默认只看错题**，可切「全部」；全对时自动回到「全部」 |

## 算式显示时长（看题心算，单位 ms）

| 选项 | 行为 |
| --- | --- |
| 不限 | 算式一直显示 |
| 500 / 1000 / 2000 ms | 到点后算式变灰并替换为 `？ ？ ？`，只剩答案输入框 |
| 自定义 | 输入任意毫秒数（50 ~ 60000），如 1500 |

- 设 1000ms：选手必须在 1 秒内记住算式，之后凭记忆计算
- 顶部会实时显示当前这一题的显示时长，如 `第 3 题 · 800ms`
- 提交后立即进入下一题，算式在结算页统一回顾
- 该设置对普通练习和「重练错题」都生效

## 除法误差范围

设置页「出题规则」里可调滑杆 **0 ~ 20%**（步长 0.5%），默认 `0%（精确）`。

| 判定 | 规则 |
| --- | --- |
| 0% | 必须与正确答案完全一致 |
| 0 < x% | `\|你的答案 − 正确答案\| ≤ 正确答案 × x%` 即判对 |

- 只对 `÷` 生效，加减乘一律精确判定
- 容差内但不等值时，结算里会在答案前标 **`≈`**，提示这是近似答案
- 用整数运算实现（百分比换算成万分比），大数也不会有浮点误差

示例（正确答案 40，容差 5%）：

```
答 38 → 判对（≈）
答 40 → 判对
答 42 → 判对（≈，正好 5%）
答 43 → 判错（7.5%）
```

## 自适应显示时长

勾选「自适应：答对缩短、答错延长」后，显示时长会随表现自动调整：

| 结果 | 下一题显示时长 |
| --- | --- |
| 答对 | 当前 × 0.8（越快记住越短） |
| 答错 / 超时 / 跳过 | 当前 × 1.3（没看清就放宽） |

- 从你设置的基准值开始（如 1000ms），一题一调
- 下限**可自定义**：滑杆 20 ~ 1000ms，默认 100ms；实际生效下限永远低于基准，保证「答对缩短」真能迈出一步
- 上限为 `max(基准×2, 3000ms)`，且不超过 60000ms；与可设置的基准范围一致，答错不会把较长基准反向缩短。到达上限后保持不变。
- 只影响「显示时长」，不影响每题限时
- 显示时长设为「不限」时自适应自动关闭（开关同步置灰）；反之在「不限」状态下开启自适应，会自动把基准设为 2000ms
- 下限滑杆的上限随基准联动：基准调小后滑杆上限跟着收紧，标签会提示「受显示时长限制」，但**你原本设定的下限值不会丢失**，基准调回来即恢复

开启自适应后，设置页会出现「自适应最低显示时长」滑杆；关闭自适应时隐藏。

示例（基准 300ms、下限 40ms）：

```
300 → 240 → 190 → 150 → 120 → 100 → 80 → 60 → 50 → 40（触底）
```

> 修复记录：旧版直接拿「显示时长」当下限的上限，当下限 >= 基准时（如基准 100ms + 默认下限 100ms、基准 1000ms + 下限拉到 1000ms），答对后 `×0.8` 会被下限顶回原值，表现为「自适应开着但数字一直不动」。现在下限上限固定为「基准的 0.8 一步」，与上限 `max(基准×2, 3000)` 对称，任何基准都能正常增减。

## 自定义设置

| 设置 | 预设 | 自定义范围 |
| --- | --- | --- |
| 题目数量 | 每种运算独立输入 / 无限 | 每种运算 0 ~ 999 题（至少一种大于 0） |
| 每题限时 | 不限 / 10s / 20s / 30s | 1 ~ 600 秒 |
| 算式显示时长 | 不限 / 500 / 1000 / 2000 ms | 50 ~ 60000 ms |
| 自适应 | 开 / 关 | 见上节 |
| 自适应下限 | 滑杆 20 ~ 1000ms | 默认 100ms，不超过基准 |
| 除法误差范围 | 滑杆 0 ~ 20% | 默认 0%，仅对除法生效 |

选中「自定义」会就地展开输入框，边输入边生效，标签实时显示当前值（如 `37 题`、`45 秒`、`800 ms`）。

## 进位 / 借位要求

| 选项 | 含义 |
| --- | --- |
| 不限 | 不约束 |
| 必须进位 | 每题必定发生进位/借位 |
| 禁止进位 | 每位都不需要进位/借位 |

判定口径：`＋` 某列相加 ≥10 ／ `－` 某位不够减 ／ `×` 竖式相乘出现进位 ／ `÷` 需退位（商的位数 < 被除数位数）。

示例：`23+14=37` 无进位（不会出现在必须进位模式）／`27+9=36` 有进位／`99−12=87` 无借位／`54−9=45` 有借位。

实现：加减法用缓存的**逐位动态规划**，按合法数对计数直接抽样；无进位乘法按每个因数的最大数字分组，再按合法组合数量抽取；除法用上下界直接构造有限整数/一位小数商。没有 2000 次拒绝采样循环，也不放宽位数或进位要求。非负减法要求 A 位数不小于 B 位数。为兼容原有选择规则，除法不支持“禁止进位”，一位 A/B 的“必须进位”组合仍提示调整。

## 乘数不出现 1

`×` 的两个乘数都保证 **≥ 2**，不会出现 `28 × 1`、`1 × 6`、`1 × 1` 这类没有练习价值的题。

| 场景 | 旧版 ×1 出现率 | 现在 |
| --- | --- | --- |
| 不限进位 · A2/B1 | 11.3% | 0% |
| 不限进位 · A1/B1 | 21.1% | 0% |
| 禁止进位 · A1/B2 | 49.7% | 0% |
| 禁止进位 · A1/B1 | 66.7% | 0% |

- 不限进位：直接从合法整数范围取样，一位乘数范围是 2–9，无重抽。
- 必须进位：个位数对从乘积 ≥10 的完整集合构造，其他数字仍独立取样。
- 禁止进位：两个因数的最大数字乘积 <10，精确计数后抽样。该口径与原有「竖式各部分乘积行有无进位」一致。
- `A=1/B=1` 的禁止进位模式仍只有 `(2,2)、(2,3)、(2,4)、(3,2)、(3,3)、(4,2)` 六种组合，这是数学限制。

## 数据分析

进入后先选**数据范围**：全部 / 最近 7 天 / 今天，所有指标随之刷新。

- **总览 6 项**：正确率、题数、平均用时、总练习时长、练习天数、最长连对、错题数
- **最近 10 次练习**：每次练习（间隔 >5 分钟自动切分）的正确率柱状图，悬停看题数与时间
- **按算子**：`＋ － × ÷` 的正确率 + 题量 + 平均用时
- **进位 / 借位表现**：有进位 vs 无进位的正确率与用时对比
- **用时分布**：2 秒内 / 2-5 / 5-10 / 10 秒以上 的题量占比，并对比「答对平均用时 vs 答错平均用时」
- **难度分桶**：A+B 位数（≤4 / 5-8 / 9-12 / >12）的正确率与用时
- **最近 7 天**：每日题量柱状图
- **导出 CSV**：导出当前所选时间范围内的原始作答记录（时间、算子、位数、是否进位、对错、用时），可用 Excel 打开
- 可一键清空

数据存本机 `localStorage`（上限 2000 条滚动保留），不上传任何服务器。统计通过一次遍历形成各算子、进位、用时、位数、日期和会话桶；重复打开时复用缓存，记录变化、本地跨日或滚动七天记录过期时重新计算。

## iPad 居中训练布局

- 题干居中偏上，答案框居中，下方是**一个完整的大数字键盘**，不拆成左右两套。
- 平板横竖屏以及连接触控板时都采用同一布局，训练期间隐藏侧栏，以屏幕中线而不是右侧内容栏中线对齐。
- 按键高度随可用屏幕高度调整，常规平板为 56–84px，Safari 工具栏较高时自动压缩辅助留白，保持提交按钮同屏。
- 左右手可操作同一键盘；同时按下不同按键时按触控事件到达顺序录入，配对 click 分别去重。
- 新增两指触控与居中单键盘结构测试；浏览器验证覆盖 768×1024、1024×768、1180×820、1194×834、1366×1024 和低高度横屏。浏览器尺寸模拟不等同于实机手感测试。

## 代码优化与资源管理

- **纯核心**：`assets/core.js` 在浏览器与 Node 使用相同接口，无 DOM 依赖；页面、测试和离线构建共享一个实现。
- **按需出题**：启动只验证最多四种运算并洗牌算子列表，显示下一题时才生成具体数字；3996 题的题型配额保持精确，无启动时批量构造 BigInt 对象。
- **精确判分**：整数和有限小数转换为 BigInt 分子/分母，容差通过整数交叉相乘判断。`14.4` 在 ±5% 下，`13.68` 与 `15.12` 均正确；差一点超界即判错。`42.0` 和 `42` 视为同一个精确数值。
- **保存调度**：设置输入防抖 180ms，不变的值不重复写；作答记录在 500ms 窗口内合并保存。完成设置、结束练习、切换视图、隐藏页面或 `pagehide` 时立即补齐；突然进程崩溃仍可能丢失尚未保存的短窗口数据。
- **计时清理**：维护题目截止、隐藏、视觉刷新与换题句柄；旧题回调通过编号失效。隐藏页面停止视觉刷新但保留真实截止；提交与跳过都按同一截止时间判定，超时时每题用时最多记为设置的限时。
- **有限/无限模式**：有限题量保留整轮回顾；无限模式只保留最近 2000 题的逐题回顾和错题重练，页面明确提示。整轮正确率、最快、平均时间与最长连对使用增量计数器，覆盖整轮，不随回顾截断。每次仅渲染 100 条回顾，可继续加载。
- **兼容**：站点样式、玩法和三个 `localStorage` 键保持不变；无新增第三方运行时依赖。CSV 仍导出当前范围内保留的作答记录。

### 本机测量（仅作比较，不代表所有设备）

基线：`a6fbfc948fd8069e434779826c9c8c81351f113e`，Linux x64，Chrome 159，1440px，相同 2000 条记录，串行执行 9 次取中位数。浏览器指标包含真实 DOM 更新和同步布局，不包含异步绘制：

| 场景 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 启动 999 道六位无进位加法 | 150.8ms | 15.2ms |
| 重复打开 2000 条记录的统计页 | 28.3ms | 12.3ms |

Node 核心微测另外记录生成/准备/序列化开销；与浏览器端到端指标分开，避免把核心速度当成全页面速度。复现：

```sh
git show a6fbfc948fd8069e434779826c9c8c81351f113e:assets/app.js > before.js
node scripts/benchmark.cjs before.js
```

浏览器测量脚本 `scripts/browser-benchmark.js` 会写入测试记录，只用于独立测试浏览器：首次执行播种，刷新后再执行测量。不要在存有个人练习记录的浏览器里执行。
