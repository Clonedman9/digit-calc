# 位数计算器 · Digit Calc

一个纯前端的大数计算小程序：**可自定义算子**，**可设置参与运算的位数与结果精度**。
基于原生 `BigInt` 实现精确整数运算，支持到数百位大数，零依赖、零后端。

🔗 在线使用：https://clonedman9.github.io/digit-calc/

## 功能

| 能力 | 说明 |
| --- | --- |
| 算子切换 | `＋` `－` `×` `÷` `xʸ`（乘方） `mod`（取模） |
| 操作数位数 | 1 ~ 120 位，滑动调节，一键随机生成 |
| 结果小数位 | 0 ~ 30 位精度，除法 / 负指数自动四舍五入 |
| 大数支持 | `BigInt` 精确整数运算，结果上限 4000 位 |
| 实时计算 | 输入或切换算子即时出结果，无需点按钮 |
| 历史记录 | 本地 `localStorage` 保存，点击记录可回填 |
| 主题 | 深色 / 浅色一键切换 |

## 技术要点

- **不丢精度**：数字被解析为 `{ m: BigInt, s: 小数位数 }`，即 `m × 10^-s`，所有运算在整数域完成后再还原小数点。
- **除法**：按设定精度做「四舍五入（half away from zero）」，并检测分母质因子是否只含 `2` 和 `5` 来判断结果能否整除。
- **乘方**：快速幂（binary exponentiation），指数支持 `-64 ~ 64`。
- **取模**：仅支持整数，符号跟随被除数。

## 本地运行

无需构建，直接打开 `index.html` 即可；或起一个静态服务：

```bash
python3 -m http.server 8080
# 打开 http://localhost:8080
```

